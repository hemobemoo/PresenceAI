# PresenceAI

Adaptive, privacy-preserving presentation and communication coach (graduation project, Al-Balqa Applied University, Faculty of Artificial Intelligence).

This repository currently contains the **starter kit**: agent rules, MCP configuration, the full plan in `docs/plan/`, and a setup checker. The code skeleton is generated by the first Claude Code session (`/kickoff`).

## Start here

1. Follow `docs/plan/FINAL_13_SETUP_GUIDE.md`.
2. `uv run python scripts/check_setup.py --online` must show no failures.
3. Open Claude Code in this folder and run `/kickoff`.

## Plan

`docs/plan/FINAL_00_README_DECISIONS.md` lists every design decision and links to the other files.
